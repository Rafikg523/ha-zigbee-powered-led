# ha-zigbee-powered-led

Plan integracji Home Assistant dla sterowników LED Zigbee zasilanych przez fizyczne przekaźniki, z wykorzystaniem MQTT i natywnych grup Zigbee2MQTT.

Projekt jest na etapie planowania. Lista prac i kryteria odbioru znajdują się w [ROADMAP.md](ROADMAP.md). Nie jest to jeszcze działająca integracja. Oryginalna specyfikacja jest przechowywana lokalnie.

Przed aktywnym wdrożeniem wymagane są inwentaryzacja, kopia zapasowa, plan rollbacku i wyłączenie konfliktujących ścieżek sterowania.
