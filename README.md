# ha-zigbee-powered-led

Plan integracji Home Assistant dla sterowników LED Zigbee zasilanych przez fizyczne przekaźniki, z wykorzystaniem MQTT i natywnych grup Zigbee2MQTT.

Projekt jest na etapie planowania. Kontraktem funkcjonalnym jest dołączona specyfikacja w `docs/specification-v0.1.md`; lista prac znajduje się w [ROADMAP.md](ROADMAP.md). Nie jest to jeszcze działająca integracja.

Pilotaż obejmuje dwa obwody LED1R/L1 i LED2R/L2 oraz grupę `ledy_rafal`. Nazwy i mapowania należy zweryfikować w instalacji. Przed aktywnym wdrożeniem wymagane są inwentaryzacja, kopia zapasowa, plan rollbacku i wyłączenie konfliktujących ścieżek sterowania.
